# 前端功能迁移与模块重构方案（2026Q1）

更新时间：2026-03-03

## 1. 目标

- 将旧 `/train-ui`（Gradio）能力按业务域重组到新前端（Vue）。
- 旧功能先保留，采用“双轨运行”，新页面成熟后再下线旧入口。
- 统一执行入口收敛到任务中心；业务页面负责配置、触发与结果展示。

## 2. 新界面模块划分

1. 任务中心
- 任务创建、执行、监控、重试、取消、结果查询（推理/训练统一）。

2. 数据中心
- 数据采集、降采样数据列表、数据预览、文件管理。

3. 标注中心
- 标注工作台、预标注导入、标注记录管理、审核队列、样本溯源。

4. 推理中心
- 推理参数配置、输入选择、任务提交、结果查看。

5. 训练中心
- 训练配置选择、任务提交、训练状态与日志、模型评估。

6. 资产中心
- 数据集构建、数据集导出、模型资产与版本管理。

7. 系统与文档
- 配置说明、运行指引、排障入口。

## 4. 现阶段新前端已上线页面

- `/data-center`：数据中心（采集任务提交、状态日志、降采样数据预览）
- `/annotation-center`：标注中心（点位视图、时间线、内嵌 Annotator）
- `/assets`：数据资产列表（已修复 404 路径问题）
- `/annotator`：兼容入口（重定向到 `/annotation-center`）
- `/inference`：新建推理任务（走任务中心分发）
- `/training`：新建微调任务（走任务中心分发）
- `/task-center`：任务运行看板（含运行态、重试、取消；高级能力按开关显示）

## 5. 分期落地计划

## Phase 1：业务闭环优先（推荐先做）

- 目标：跑通“采集 -> 标注/审核 -> 构建资产”。
- 开发项：
  - 新增“数据中心”页面：采集、预览、删除、数据列表。
  - 新增“标注中心”页面：标注记录管理、审核队列。
  - 标注中心与 `/annotator` 内嵌页联动（刷新、回流提示）。

## Phase 2：执行闭环增强

- 目标：推理与训练全流程可在新界面完成。
- 开发项：
  - 推理中心补齐历史、结果详情、导出入口。
  - 训练中心补齐任务日志、模型产物列表、评估入口。
  - 与任务中心打通“从详情反查运行实例”。

## Phase 3：资产与运营能力

- 目标：完成资产与对比能力，具备下线旧 UI 的前提。
- 开发项：
  - 资产中心补齐构建/导出/冻结/删除。
  - 模型对比与模型资产页面迁移。
  - 系统与文档页面迁移，形成统一操作手册入口。

## 6. 验收标准（建议）

1. 功能可用性
- 关键链路：采集、标注、审核、推理、训练、资产构建均可在新界面完成。

2. 执行一致性
- 新旧入口对同一任务产生一致的状态与结果（以 DB/API 为准）。

3. 监控可观测
- 任务状态、日志、结果可查询，失败可重试/取消。

4. 回退安全
- 旧 `/train-ui` 保持可用，任一模块迁移失败可快速回退到旧入口。

## 9. 移植可用性评估（2026-03-03）

### 9.1 已可用能力（可上线试运行）

- 数据中心：IoTDB 创建数据集、CSV 上传创建数据集、数据列表与预览。
- 标注中心：队列查询、批量审核状态更新、点位详情与时间线、Annotator 内嵌入口。
- 推理中心：选择数据集文件提交推理任务。
- 训练中心：提交微调任务并在任务中心查看运行状态。
- 任务中心：运行实例查询、执行、取消、重试与详情查看。

### 9.2 遗留能力（尚未完全迁移）

- 模型资产对比页仍为占位实现（`/models`）。
- 旧 Gradio 的“已训练模型管理、模型对比细项、配置说明页”尚未迁移到新前端独立页面。
- 资产中心中的“构建/导出细化流程”仍有部分能力停留在旧入口。

### 9.3 当前优化优先级

1. P0：补齐 `/models` 真实页面，替换占位路由。
2. P0：补前端 E2E 烟测（数据集上传 -> 推理任务提交 -> 任务中心查询）。
3. P1：标注中心增加“按方法/评分/更新时间”排序与分页，提升大规模数据可用性。
4. P1：数据中心补“数据集删除/重命名”能力。
5. P2：页面级错误提示与重试机制统一（网络错误、后端 4xx/5xx）。
